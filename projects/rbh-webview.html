같은 기능을 여러 화면에서 고치던 문제

AI 서비스 꾸미의 Flutter 앱을 React WebView로 전환하고 구조를 개선했습니다. 결과 화면 3종에서 같은 기능을 반복 수정해야 하는 문제를 다뤘습니다.

02

공통 UI·훅·설정을 나누기

반복되는 UI와 동작을 공통으로 분리하고 화면별 차이는 설정으로 표현했습니다. 신규 공통 파일을 포함한 결과 페이지 관련 코드가 595줄에서 376줄로 약 37% 줄었습니다. 이 수치는 해당 코드 범위의 변화이며 앱 전체 크기나 개발시간 감소율은 아닙니다.

03

크레딧 조회와 변경을 화면에서 분리

크레딧 조회·충전을 API, 조회·변경 훅, UI로 구분했습니다. 이미지 생성 이후 잔액이 갱신되지 않는 흐름도 수정했습니다.
