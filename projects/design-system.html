공용 API와 사용 예시를 갖춘 Toast 구현이 npm 배포 패키지에 포함

01

화면에서 사용할 알림 API

설명·액션 버튼·닫기 버튼을 조합하고 사내 디자인에 맞게 표현할 Toast가 필요했습니다. React Aria의 Toast 구성 요소와 큐를 사용하고, 그 위에 사내 디자인 토큰과 공용 API를 구현했습니다.

02

소비 화면과 렌더링의 역할 분리

화면에서는 제목·설명·상태·크기·액션·닫기 여부를 전달하도록 했습니다. toast.success, toast.error 등 호출 API를 제공하고 ToastRegion이 공통 렌더링을 담당하게 구성했습니다.

03

닫기 요청과 실제 제거 사이

종료 애니메이션을 위해 닫기 요청이 오면 종료 상태를 먼저 알리고 지정한 시간 뒤 큐에서 제거했습니다. 이미 닫는 중인 항목은 중복 요청을 무시합니다. 진입·종료 상태는 useSyncExternalStore로 구독하고 움직임 감소 설정을 위한 스타일도 포함했습니다.

04

배포와 기여 범위

상태·크기·긴 문구·액션·닫기 조합을 Storybook으로 정리했습니다. 구현은 병합됐고 npm 패키지 실행 코드와 타입 선언에 포함돼 있습니다. React Aria가 큐와 구성 요소를 제공했으며, 스타일 빌드 규칙·토큰 import·일부 타입은 동료가 후속 보정했습니다.
