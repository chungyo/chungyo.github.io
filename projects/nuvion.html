01

배경: 영상을 보여주면서 운영 상태도 확인해야 한다

NUVION은 실시간 영상 모니터링 서비스입니다. 카메라 영상을 브라우저에서 수신하는 흐름과 대시보드의 통합 로그·알림 화면을 개발했습니다.

이 사례의 담당 범위는 영상 수신·연결과 운영 UI입니다. 영상 분석 AI 모델 자체를 개발하거나 장비·네트워크 전체를 단독 설계한 경험으로 설명하지 않습니다.

02

구조: 영상 수신과 연결 신호를 나누기

WebRTC 수신과 WebSocket/STOMP 시그널링을 연결했습니다. 카메라별 메시지를 처리하고 연결·통신 로직을 화면의 렌더링 코드에서 분리했습니다.

위 도식은 확인한 구현의 책임을 정리한 것입니다. 운영 환경의 특정 네트워크 지연이나 장애 원인을 재현했다는 뜻은 아닙니다.

03

핵심 구현: 화면의 종료와 통신 수명주기 맞추기

영상은 연결을 시작하는 것만으로 끝나지 않습니다. 시청을 종료하거나 화면을 떠날 때 연결·구독도 함께 정리해야 합니다. 구현에서 시청 종료와 구독 해제를 다뤘습니다.

연결의 단계별 책임
단계구현에서 다룬 내용확인할 동작
연결 준비카메라별 메시지·시그널링메시지 대상 구분
연결 협상offer/answer·ICE 교환브라우저 수신 연결
시청 중영상 카드 상태·통신 로직연결 상태의 화면 표현
시청 종료연결·구독 정리종료 이후 자원 수명주기

기존에 어떤 운영 장애가 얼마나 발생했는지에 대한 측정은 확보되지 않았습니다. 예방·정리 구현을 장애 감소율로 바꾸지 않고 코드에서 확인한 동작으로 설명합니다.

04

운영 화면: 영상 외의 정보를 같은 서비스에서

대시보드에 통합 로그 조회와 해결 처리, 알림 화면을 개발했습니다. 데스크톱에서는 알림 패널, 모바일에서는 페이지 형태를 다뤘습니다.

개발한 화면과 데이터 책임
영역담당 범위연결
영상 카드상태별 UI카메라 연결·메시지
통합 로그조회·해결 처리API·query·화면
알림데스크톱 패널·모바일 페이지기기 화면 크기에 맞는 UI

카메라 연결과 로그·알림은 서로 관련되지만 같은 기능은 아닙니다. 작성 이력에서 확인한 화면과 데이터 연결의 범위로 나눠 설명합니다.

05

검증 기반과 실제 운영 검증의 차이

Vitest·Testing Library·MSW 기반 테스트 환경과 상태별 UI, 명세·테스트 연결 기준을 도입했습니다. 인증·API 계약·영상·알림 등 기능별 검증 절차도 정리했습니다.

확인된 근거와 확인하지 않은 지표
항목확인 내용별도 확인
영상 연결 코드시그널링·ICE·구독 해제실제 모든 장비·네트워크 조합
화면·테스트 기반상태별 UI·검증 환경현재 운영의 전체 회귀 결과
성능·안정성이 사례에서 제시할 실측 없음영상 지연·동시 시청·장애율
수상NUVION으로 AI혁신 프로토타이핑 챌린지 총장상·전체 2위팀 서비스 결과와 개인 기여 구분

이번 글 작성에서 카메라나 운영 API를 직접 연결하지 않았습니다. 회사 코드의 변경과 당시 검증 기반을 확인한 설명이며 현재 서비스의 성능 보증이 아닙니다.

06

이 사례의 구현 기준

실시간 화면의 관심사를 영상 표시, 카메라별 메시지 처리, 연결 협상, 시청 종료로 나누었습니다. 이 구분을 통해 화면을 만든 기여와 통신 수명주기를 구현한 기여를 각각 설명할 수 있습니다.

팀 서비스의 수상과 프론트엔드 담당 범위도 같은 방식으로 나눕니다. 수상 자체를 연결 지연이나 운영 안정성의 측정값으로 대신하지 않습니다.
