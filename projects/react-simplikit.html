useStorageState와 useRefEffect 수정 PR 2건 병합

01

다른 탭의 전체 삭제를 놓치는 이벤트

탭 B에서 localStorage.clear()를 실행하면 탭 A에는 이전 값이 남았습니다. 전체 삭제의 StorageEvent.key는 null인데 기존 코드는 관찰하는 key와 일치하는 이벤트만 처리했습니다. null일 때도 구독자를 깨워 기존 snapshot 로직이 저장소를 다시 읽게 수정했습니다.

02

ref가 effect보다 먼저 부착되는 경우

의존성이 A에서 B로 바뀌었는데 ref 부착이 effect보다 먼저 실행되면서 이전 콜백을 읽어 setup(A)가 다시 호출됐습니다. useIntersectionObserver에서도 옵션 변경 시 이전 observer에 요소를 붙이는 문제로 이어졌습니다.

03

의존성별로 콜백을 보관하기

의존성이 바뀔 때 콜백을 담는 객체를 새로 만들도록 수정했습니다. 의존성이 같을 때 effect에서 콜백을 갱신하는 기존 의미는 유지했습니다. 렌더 중 기존 객체를 덮어쓰지 않아 미커밋 렌더의 콜백이 현재 동작에 섞이지 않도록 했습니다.

04

리뷰와 검증

당시 검증에는 기본값 복원·저장소 구분, StrictMode·observer 옵션 변경·DOM 교체·미커밋 렌더 테스트가 포함됐습니다. 브라우저 확인과 React 18·19 및 React Compiler 모드 테스트도 기록했습니다. #482는 2026년 9월 8일, #483은 9월 9일 병합됐습니다. 패키지 릴리즈 포함 여부와는 별도입니다.
