예약 관리 업무시간 약 50% 절감 — 현장 직원·대표 피드백 기준

01

분리돼 있던 네이버 예약과 현장 접수

네이버 예약은 외부 서비스에서 처리하고 현장 방문 고객은 별도로 관리하던 환경이었습니다. 고객은 두 경로를 통합하기를 원했습니다. 창업 초기 첫 고객 프로젝트에서 기획과 화면 구성이 없는 상태부터 요구사항 정리, 화면 구성, UI 개발과 API 연동을 담당했습니다.

02

약 2주 만에 첫 사용 가능한 버전

팀의 예약 통합 기능을 사용자가 한 화면에서 다룰 수 있도록 대시보드와 예약 화면을 구성했습니다. 약 2주는 첫 사용 가능한 버전을 구축한 기간이며 이후의 모든 운영 기능 개선까지 포함한 기간은 아닙니다.

03

현장에서 확인한 반복 조작을 줄이기

팀과 현장을 방문해 반복 조작의 불편을 확인했습니다. 주요 예약 상태를 바꿀 때 상세 화면에 들어가지 않고 카드 슬라이드와 확인 단계로 처리하도록 UX를 설계·구현했습니다. 예약 시간·상품 변경과 실제 이용일 기준 매출 집계도 개선했습니다.

04

고객 피드백과 본인 기여의 범위

현장 직원과 대표에게 예약 관리 시간이 절반 정도 줄었다는 피드백을 직접 들었습니다. 약 50%는 이 피드백을 기준으로 한 수치이며 별도의 전후 시간 로그 실측값은 아닙니다. 예약 수집·백엔드 동기화를 포함한 전체 시스템은 팀의 작업이고, 본인의 담당은 기획·화면·프론트엔드와 API 연결입니다.

담당 범위

요구사항 정리 · 화면 구성 · UI 개발 · API 연동 · 현장 피드백 반영
