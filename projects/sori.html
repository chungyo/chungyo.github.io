01

아이디어와 팀의 개발 준비

소상공인의 마케팅 콘텐츠 생성을 돕는 서비스 아이디어를 제안했습니다. 개발 경험이 적은 팀원들과 스터디를 진행하고 생성 입력·결과·기록·가게 관리 화면을 개발했습니다.

02

진행률이 먼저 끝나버리는 화면

콘텐츠 생성에 시간이 걸리는데 화면의 진행률이 먼저 끝나 결과를 받기 전에 홈으로 이동하는 문제가 있었습니다. 화면에 표시한 진행률과 실제 응답 완료가 다른 상태였습니다.

03

결과 수신과 화면 전환을 연결

결과를 기다리는 상태와 화면 이동을 분리했습니다. 결과 ID를 받았을 때 결과 화면으로 이동하도록 수정하고 별도 타임아웃은 유지했습니다.

04

구현 범위

대기 화면의 진행률은 실제 서버 작업 비율을 뜻하지 않습니다. 이 사례의 기여는 결과 수신 전의 화면 이동 문제와 결과 ID를 받은 뒤의 전환 처리이며, 콘텐츠 생성 모델 자체의 개발을 의미하지 않습니다.
